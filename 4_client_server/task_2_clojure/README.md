# 4.2. Сервер RLE-сжатия и распаковки

**Тема:** Клиент-серверное взаимодействие

**Язык:** Clojure

**Ветка:** `4_task_2_clojure`

## Постановка задачи

Реализовать TCP-клиент и сервер для простого кодирования повторяющихся символов методом RLE (Run-Length Encoding).

Клиент отправляет команду `ENC` со строкой из заглавных латинских букв или `DEC` с последовательностью пар «число повторений — буква».

Например, `AAABB` кодируется как `3A2B`, а `3A2B` распаковывается в `AAABB`.

Сервер выполняет операцию и возвращает результат; некорректные команды и данные обрабатываются с сообщением об ошибке. Число повторений может содержать несколько цифр.

**Входные данные:** команды `ENC <строка>` и `DEC <пары>`, передаваемые клиентом TCP-серверу.

**Выходные данные:** результат RLE-кодирования или декодирования либо сообщение об ошибке, выводимое клиентом в консоль.

## Компиляция и запуск

Из корневой папки репозитория:

Запуск сервера в первом терминале:

```bash
clojure -M 4_client_server/task_2_clojure/server.clj
```

Запуск клиента во втором терминале:

```bash
clojure -M 4_client_server/task_2_clojure/client.clj ENC AAABB
```

Для декодирования:

```bash
clojure -M 4_client_server/task_2_clojure/client.clj DEC 3A2B
```

Сервер работает по адресу `127.0.0.1:5052`. Остановка — `Ctrl + C`.

## Пример работы

**Кодирование строки `AAABB`:**

```text
3A2B
```

**Декодирование последовательности `3A2B`:**

```text
AAABB
```

**Декодирование последовательности `12A3B`:**

```text
AAAAAAAAAAAABBB
```

Метод RLE заменяет последовательности одинаковых букв количеством повторений и самой буквой. При декодировании исходная строка восстанавливается.

Сервер обрабатывает команды последовательно, проверяет корректность данных и возвращает результат клиенту.
