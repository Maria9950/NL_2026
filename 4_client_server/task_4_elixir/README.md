# 4.4. Сетевой конвертер температуры

**Тема:** Клиент-серверное взаимодействие

**Язык:** Elixir

**Ветка:** `4_task_4_elixir`

## Постановка задачи

TCP-клиент отправляет серверу числовое значение температуры в градусах Цельсия. Сервер переводит его в градусы Фаренгейта по формуле `F = 1.8 * C + 32` и возвращает результат. Некорректные значения обрабатываются с сообщением об ошибке.

**Входные данные:** числовое значение температуры в градусах Цельсия, передаваемое клиентом TCP-серверу.

**Выходные данные:** температура в градусах Фаренгейта либо сообщение об ошибке для некорректных данных.

## Компиляция и запуск

Из корневой папки репозитория.

Программы запускаются непосредственно через Elixir без предварительной компиляции.

**Первый терминал — запуск сервера:**

```bash
elixir 4_client_server/task_4_elixir/server.exs
```

Сервер работает по адресу `127.0.0.1:5054` и ожидает подключения клиентов.

**Второй терминал — запуск клиента:**

Перевод 0 °C:

```bash
elixir 4_client_server/task_4_elixir/client.exs 0
```

Перевод 100 °C:

```bash
elixir 4_client_server/task_4_elixir/client.exs 100
```

Перевод дробного значения:

```bash
elixir 4_client_server/task_4_elixir/client.exs 36.6
```

Для остановки сервера используется `Ctrl + C`, затем `a` и `Enter`.

## Пример работы

При передаче температуры `0` °C сервер возвращает:

```text
32
```

При передаче температуры `100` °C:

```text
212
```

При передаче температуры `-40` °C:

```text
-40
```

При передаче температуры `36.6` °C:

```text
97.88
```

При передаче некорректного значения `25abc`:

```text
ERROR: неверный формат числа, ожидается, например, 25, -40, +3.5
```

Сервер преобразует полученное значение в число, вычисляет температуру по формуле `F = 1.8 * C + 32` и возвращает результат клиенту.

Сервер последовательно обрабатывает TCP-подключения и продолжает работу после каждого запроса.
