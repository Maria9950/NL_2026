# 4.3. Сетевая проверка палиндрома

**Тема:** Клиент-серверное взаимодействие

**Язык:** Erlang

**Ветка:** `4_task_3_erlang`

## Постановка задачи

TCP-клиент передаёт серверу строку, содержащую латинские буквы и пробелы. Сервер проверяет, является ли строка палиндромом без учёта регистра букв и пробелов, и возвращает ответ `YES` или `NO`. Клиент отображает ответ в консоли.

**Входные данные:** строка из латинских букв и пробелов, передаваемая клиентом TCP-серверу.

**Выходные данные:** `YES`, если строка является палиндромом, `NO` — если не является, либо сообщение об ошибке для некорректных данных.

## Компиляция и запуск

Из корневой папки репозитория.

Компиляция обоих файлов:

```bash
erlc -o /tmp 4_client_server/task_3_erlang/server.erl 4_client_server/task_3_erlang/client.erl
```

**Первый терминал — запуск сервера:**

```bash
erl -noshell -pa /tmp -s server main
```

Сервер работает по адресу `127.0.0.1:5053` и ожидает подключения клиентов.

**Второй терминал — запуск клиента:**

Проверка палиндрома:

```bash
erl -noshell -pa /tmp -s client main -extra "Never odd or even"
```

Проверка строки, не являющейся палиндромом:

```bash
erl -noshell -pa /tmp -s client main -extra "Hello world"
```

Проверка длинной фразы:

```bash
erl -noshell -pa /tmp -s client main -extra "A man a plan a canal Panama"
```

Для остановки сервера используется `Ctrl + C`, затем `a` и `Enter`.

## Пример работы

При проверке строки `Never odd or even` сервер возвращает:

```text
YES
```

Строка преобразуется в `neveroddoreven`, которая одинаково читается в обоих направлениях.

При проверке строки `Hello world`:

```text
NO
```

При проверке фразы `A man a plan a canal Panama`:

```text
YES
```

При передаче некорректной строки `Hello, world!`:

```text
ERROR: допустимы только латинские буквы и пробелы
```

Сервер проверяет допустимость символов, удаляет пробелы и приводит буквы к нижнему регистру. Полученная последовательность сравнивается со своей обратной записью.

Сервер обрабатывает TCP-подключения последовательно и продолжает работу после каждого запроса.
