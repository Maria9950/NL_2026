# 4.1. Сервер бронирования временных интервалов

**Тема:** Клиент-серверное взаимодействие

**Язык:** Scala

**Ветка:** `4_task_1_scala`

## Постановка задачи

Реализовать TCP-сервер, который хранит в памяти список забронированных интервалов времени в пределах одних суток.

Клиент отправляет команду `BOOK HH:MM HH:MM` для добавления бронирования или `LIST` для просмотра интервалов.

Сервер подтверждает запись только при корректном времени и отсутствии пересечений с существующими бронированиями; соседние интервалы с общей границей разрешены.

Клиент выводит ответ сервера. Хранение в базе данных, учёт дат и одновременное обслуживание нескольких клиентов не требуются.

**Входные данные:** текстовые команды `BOOK HH:MM HH:MM` и `LIST`, передаваемые клиентом TCP-серверу.

**Выходные данные:** ответы сервера о результате бронирования, ошибках или текущем списке интервалов, выводимые клиентом в консоль.

## Компиляция и запуск

Из корневой папки репозитория.

Scala CLI автоматически компилирует и запускает программы. Сервер и клиент запускаются в двух отдельных терминалах.

**Первый терминал — запуск сервера:**

```bash
scala-cli run --server=false --workspace /tmp 4_client_server/task_1_scala/Server.scala
```

Сервер работает по адресу `127.0.0.1:5051` и ожидает подключения клиентов.

**Второй терминал — запуск клиента:**

Просмотр списка бронирований:

```bash
scala-cli run --server=false --workspace /tmp 4_client_server/task_1_scala/Client.scala -- LIST
```

Бронирование интервала с 09:00 до 10:00:

```bash
scala-cli run --server=false --workspace /tmp 4_client_server/task_1_scala/Client.scala -- BOOK 09:00 10:00
```

Бронирование соседнего интервала:

```bash
scala-cli run --server=false --workspace /tmp 4_client_server/task_1_scala/Client.scala -- BOOK 10:00 11:00
```

Попытка забронировать пересекающийся интервал:

```bash
scala-cli run --server=false --workspace /tmp 4_client_server/task_1_scala/Client.scala -- BOOK 09:30 10:30
```

Для повторного просмотра списка используется команда `LIST`.

Сервер останавливается сочетанием `Ctrl + C` в первом терминале.

## Пример работы

При первом запросе `LIST` сервер возвращает:

```text
Список бронирований пуст.
```

После выполнения команды `BOOK 09:00 10:00`:

```text
OK: забронировано 09:00-10:00.
```

Следующий соседний интервал `BOOK 10:00 11:00` также принимается:

```text
OK: забронировано 10:00-11:00.
```

Попытка забронировать пересекающийся интервал `BOOK 09:30 10:30` отклоняется:

```text
ERROR: интервал 09:30-10:30 пересекается с бронированием 09:00-10:00.
```

**Результат команды `LIST`:**

```text
Бронирований: 2
09:00-10:00
10:00-11:00
```

Сервер проверяет корректность времени и отсутствие пересечений. Соседние интервалы с общей границей разрешены.

Бронирования хранятся в оперативной памяти сервера и сохраняются между последовательными подключениями клиентов. При остановке сервера данные не сохраняются.
