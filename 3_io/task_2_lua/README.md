# 3.2. Менеджер закладок с хранением в файле

**Тема:** Ввод/вывод в консоль и файл

**Язык:** Lua

**Ветка:** `3_task_2_lua`

## Постановка задачи

Реализовать консольную программу для ведения списка интернет-закладок.

Пользователь может добавить закладку с названием и URL, просмотреть все сохранённые записи, найти закладку по названию и удалить её.

Закладки сохраняются в текстовый файл и восстанавливаются при следующем запуске. Предусмотреть обработку пустого списка и некорректного ввода; для простоты названия и адреса не содержат символ `;`, используемый как разделитель полей.

**Входные данные:** команды пользователя, названия и URL закладок.

**Выходные данные:** список закладок, результаты поиска и удаления, сообщения об операциях. Данные сохраняются в текстовый файл в формате `Название;URL`.

## Запуск программы

Из корневой папки репозитория:

```bash
lua5.4 3_io/task_2_lua/main.lua /tmp/nl_3_2_lua_bookmarks.txt
```

## Пример работы

При первом запуске программа сообщает, что файл закладок ещё не создан, а список пуст.

Пользователь добавляет две закладки:

```text
Название: Википедия
URL: https://ru.wikipedia.org
Закладка «Википедия» добавлена и сохранена.

Название: Яндекс
URL: https://ya.ru
Закладка «Яндекс» добавлена и сохранена.
```

При просмотре списка:

```text
Закладок: 2
1. Википедия — https://ru.wikipedia.org
2. Яндекс — https://ya.ru
```

При поиске по названию:

```text
Название для поиска: Яндекс
Найдено: Яндекс — https://ya.ru
```

Закладки сохраняются в файле `/tmp/nl_3_2_lua_bookmarks.txt`.

При повторном запуске с тем же файлом программа восстанавливает сохранённые записи:

```text
Загружено закладок: 2
```
