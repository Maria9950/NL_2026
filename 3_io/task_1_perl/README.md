# 3.1. Учёт посещаемости студентов

**Тема:** Ввод/вывод в консоль и файл\
**Язык:** Perl\
**Ветка:** `3_task_1_perl`

## Постановка задачи

Прочитать текстовый файл журнала, в котором каждая запись содержит имя студента, дату и отметку присутствия (`1` — присутствовал, `0` — отсутствовал).

Для каждого студента определить количество посещений, пропусков и процент посещаемости. Вывести отчёт в консоль и записать его в отдельный текстовый файл.

**Входные данные:** файл `attendance.txt` с записями в формате `Имя;YYYY-MM-DD;Отметка`.

**Выходные данные:** отчёт по каждому студенту с количеством посещений, пропусков, общим числом занятий и процентом посещаемости. Отчёт выводится в консоль и сохраняется в файл.

## Запуск программы

Из корневой папки репозитория:

```bash
perl 3_io/task_1_perl/main.pl 3_io/task_1_perl/attendance.txt /tmp/nl_3_1_perl_report.txt
```

## Пример работы

**Входные данные:** `attendance.txt` — журнал из 17 записей для четырёх студентов.

**Результат:**

- Иванов Иван — 5 посещений, 0 пропусков, 100.00%.
- Козлова Мария — 2 посещения, 1 пропуск, 66.67%.
- Петрова Анна — 4 посещения, 1 пропуск, 80.00%.
- Сидоров Пётр — 0 посещений, 4 пропуска, 0.00%.

Учтено записей: 17; пропущено некорректных строк: 0.

Отчёт также сохраняется в `/tmp/nl_3_1_perl_report.txt`.
