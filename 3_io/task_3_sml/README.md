# 3.3. Построение указателя слов с номерами строк

**Тема:** Ввод/вывод в консоль и файл

**Язык:** Standard ML

**Ветка:** `3_task_3_sml`

## Постановка задачи

Прочитать текстовый файл и построить алфавитный указатель: для каждого встречающегося слова указать номера строк, в которых оно присутствует.

Слова состоят из латинских букв, регистр не учитывается, знаки препинания служат разделителями; повторение слова в одной строке не дублирует её номер.

Вывести указатель в консоль и записать его в отдельный текстовый файл. Нумерация строк начинается с 1.

**Входные данные:** текстовый файл `input.txt`, содержащий слова из латинских букв, знаки препинания и другие разделители.

**Выходные данные:** алфавитный указатель слов с номерами строк, выводимый в консоль и сохраняемый в отдельный текстовый файл.

## Компиляция и запуск

Из корневой папки репозитория:

Компиляция:

```bash
mlton -default-ann 'allowExtendedTextConsts true' -output /tmp/nl_3_3_sml_main 3_io/task_3_sml/main.sml
```

Запуск:

```bash
/tmp/nl_3_3_sml_main 3_io/task_3_sml/input.txt /tmp/nl_3_3_sml_index.txt
```

## Пример работы

**Входные данные:** `input.txt` — текст из шести строк, включая одну пустую строку. Слова встречаются в разных регистрах, повторяются и разделяются знаками препинания и цифрами.

**Фрагмент результата:**

```text
dog: 1, 2, 5
fox: 1, 2, 5
hello: 4
quick: 1, 6
the: 1, 2, 6
```

Всего найдено 23 различных слова.

Повторные вхождения слова в одной строке учитываются только один раз. Все слова сортируются по алфавиту, а номера строк выводятся по возрастанию.

Полный указатель выводится в консоль и сохраняется в файле `/tmp/nl_3_3_sml_index.txt`.
