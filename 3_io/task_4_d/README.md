# 3.4. Сортировка товаров по цене

**Тема:** Ввод/вывод в консоль и файл

**Язык:** D

**Ветка:** `3_task_4_d`

## Постановка задачи

Прочитать текстовый файл, содержащий названия товаров и их цены в формате `название;цена`.

Отсортировать записи по возрастанию цены. Вывести отсортированный список в консоль и сохранить его в новый файл; некорректные записи обрабатывать с сообщением об ошибке.

**Входные данные:** текстовый файл `products.txt`, содержащий названия товаров и их цены, разделённые символом `;`.

**Выходные данные:** список товаров, отсортированный по возрастанию числового значения цены. Результат выводится в консоль и сохраняется в отдельный текстовый файл.

## Компиляция и запуск

Из корневой папки репозитория:

Компиляция:

```bash
ldc2 -of=/tmp/nl_3_4_d_main 3_io/task_4_d/main.d
```

Запуск:

```bash
/tmp/nl_3_4_d_main 3_io/task_4_d/products.txt /tmp/nl_3_4_d_sorted.txt
```

## Пример работы

**Входные данные:** `products.txt` — девять товаров с целыми и дробными ценами, расположенных в произвольном порядке.

**Результат:**

```text
Спички;9.99
Вода минеральная;25
Хлеб;45.5
Молоко;89.90
Кефир;89.9
Шоколад;100
Яблоки;120.00
Чай чёрный;120
Сыр российский;520
```

Товары отсортированы по возрастанию числового значения цены. При одинаковых ценах сохраняется исходный порядок записей.

Некорректные строки пропускаются с сообщением об ошибке и номером строки.

Отсортированный список выводится в консоль и сохраняется в файле `/tmp/nl_3_4_d_sorted.txt`.
