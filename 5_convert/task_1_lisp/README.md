# 5.1. Преобразование TSV в YAML

**Тема:** Конвертация данных из одного формата в другой

**Язык:** Common Lisp

**Ветка:** `5_task_1_lisp`

## Постановка задачи

Прочитать TSV-файл: первая строка содержит названия столбцов, последующие — значения, разделённые табуляцией. Сформировать YAML-файл в виде списка объектов, где каждый объект соответствует строке таблицы, а названия столбцов используются как ключи. Значения записывать как строки в одинарных кавычках с корректным экранированием апострофов. Имена столбцов ограничены латинскими буквами, цифрами и подчёркиванием и начинаются с буквы; поля не содержат табуляций и переводов строк.

**Входные данные:** TSV-файл с названиями столбцов в первой строке и записями, поля которых разделены табуляцией.

**Выходные данные:** YAML-файл со списком объектов, где названия столбцов используются как ключи, а значения записываются строками в одинарных кавычках.

## Компиляция и запуск

Из корневой папки репозитория:

Программа запускается через SBCL без отдельной компиляции:

```bash
sbcl --script 5_convert/task_1_lisp/main.lisp 5_convert/task_1_lisp/example.tsv /tmp/nl_5_1_output.yaml
```

Первый аргумент — путь к исходному TSV-файлу, второй — путь для сохранения результата в формате YAML.

## Пример работы

**Входные данные:** файл `5_convert/task_1_lisp/example.tsv` с четырьмя записями. Ниже представлено его содержимое в табличном виде; в самом TSV-файле поля разделены символами табуляции.

| id | name | city |
|---|---|---|
| 1 | Alice | London |
| 2 | Bob | Paris |
| 3 | O'Brien | Dublin |
| 4 | | Rome |

**Результат:** файл `/tmp/nl_5_1_output.yaml`:

```yaml
- id: '1'
  name: 'Alice'
  city: 'London'
- id: '2'
  name: 'Bob'
  city: 'Paris'
- id: '3'
  name: 'O''Brien'
  city: 'Dublin'
- id: '4'
  name: ''
  city: 'Rome'
```

При успешном выполнении программа сообщает:

```text
Готово: обработано записей: 4. Результат: /tmp/nl_5_1_output.yaml
```

Апострофы внутри значений экранируются удвоением, пустые поля сохраняются как `''`. Все значения YAML остаются строками независимо от их содержимого.

Программа проверяет корректность заголовков и количество полей в каждой записи. При ошибках выводится сообщение с описанием проблемы, а частично сформированный выходной файл не создаётся.
