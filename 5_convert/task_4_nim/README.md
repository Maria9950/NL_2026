# 5.4. Преобразование журнала Apache в JSON

**Тема:** Конвертация данных из одного формата в другой

**Язык:** Nim

**Ветка:** `5_task_4_nim`

## Постановка задачи

Прочитать файл журнала доступа веб-сервера Apache в формате Common Log Format (CLF). Для каждой корректной записи извлечь IP-адрес клиента, дату и время запроса, строку HTTP-запроса, код ответа и объём переданных данных.

Сформировать JSON-файл с массивом объектов, используя стандартный модуль `json` языка Nim. Записи с неверной структурой пропускать с сообщением в консоли; другие форматы журналов, включая Combined Log Format, не поддерживаются.

**Входные данные:** текстовый файл журнала Apache в формате Common Log Format, содержащий записи с IP-адресом клиента, датой и временем, HTTP-запросом, кодом ответа и размером переданных данных.

**Выходные данные:** JSON-файл с массивом объектов. Каждый объект содержит поля `ip`, `datetime`, `request`, `status` и `bytes`. Если размер переданных данных не указан (`-`), соответствующее значение записывается как `null`.

## Компиляция и запуск

Из корневой папки репозитория.

**Компиляция программы:**

```bash
nim c -d:release --hints:off -o:/tmp/nl_5_4_nim_main 5_convert/task_4_nim/main.nim
```

**Запуск программы:**

```bash
/tmp/nl_5_4_nim_main 5_convert/task_4_nim/example.log /tmp/nl_5_4_output.json
```

Первый аргумент — путь к исходному файлу журнала Apache, второй — путь для сохранения результата в формате JSON.

## Пример работы

**Входные данные:** файл `5_convert/task_4_nim/example.log`, содержащий семь корректных записей Common Log Format, одну некорректную запись и одну запись в формате Combined Log Format.

```text

Готово: обработано записей: 7, пропущено некорректных: 2. Результат: /tmp/nl_5_4_output.json
```
