# 5.3. Преобразование SQL INSERT в CSV

**Тема:** Конвертация данных из одного формата в другой

**Язык:** Julia

**Ветка:** `5_task_3_julia`

## Постановка задачи

Прочитать SQL-файл, содержащий команды `INSERT INTO measurements`, и преобразовать содержащиеся в них данные в формат CSV.

Имена столбцов из списка полей SQL-команды должны стать заголовками CSV-файла. Значения из каждой команды `INSERT` записываются в отдельную строку таблицы.

Программа должна поддерживать несколько команд `INSERT` в одном файле, сохранять исходное текстовое представление числовых значений, включая завершающие нули после десятичной точки, и проверять корректность входных данных.

**Входные данные:** SQL-файл с командами `INSERT INTO measurements`, содержащими список столбцов и соответствующие значения.

**Выходные данные:** CSV-файл, первая строка которого содержит названия столбцов, а последующие — значения из SQL-команд.

## Компиляция и запуск

Из корневой папки репозитория:

Программа запускается непосредственно через Julia без отдельной компиляции:

```bash
julia --startup-file=no 5_convert/task_3_julia/main.jl 5_convert/task_3_julia/example.sql /tmp/nl_5_3_output.csv
```

Первый аргумент — путь к исходному SQL-файлу, второй — путь для сохранения результата в формате CSV.

## Пример работы

**Входные данные:** файл `5_convert/task_3_julia/example.sql` с четырьмя командами `INSERT INTO measurements`:

```sql
INSERT INTO measurements (id, temperature, humidity) VALUES (1, 22.50, 45);
INSERT INTO measurements (id, temperature, humidity) VALUES (2, -3.25, 60);
INSERT INTO measurements (id, temperature, humidity) VALUES (3, 0, 100);
INSERT INTO measurements (id, temperature, humidity) VALUES (4, 18.75, 52);
```

**Результат:** файл `/tmp/nl_5_3_output.csv`:

```csv
id,temperature,humidity
1,22.50,45
2,-3.25,60
3,0,100
4,18.75,52
```

При успешном выполнении программа сообщает:

```text
Готово: обработано записей: 4. Результат: /tmp/nl_5_3_output.csv
```
