# 1.2. Моделирование работы касс

**Тема:** Многопоточность  
**Язык:** Ruby  
**Ветка:** `1_task_2_ruby`

## Постановка задачи

Создать очередь заказов, каждый из которых содержит сумму покупки. Три потока-кассира извлекают заказы из общей очереди и обрабатывают их.

Программа подсчитывает выручку каждого кассира и общую выручку; обновление общего счётчика защищено механизмом синхронизации. После обработки всех заказов потоки корректно завершают работу.

**Входные данные:** положительные целочисленные суммы заказов в рублях, вводимые через пробел.

**Выходные данные:** информация об обработанных заказах, количество заказов и выручка каждого кассира, общая выручка и результат проверки вычислений.

## Запуск программы

Из корневой папки репозитория:

`ruby 1_threads/task_2_ruby/main.rb`

## Пример работы

**Входные данные:**

`100 250 75 500 30 1200`

**Результат:**

- Обработано заказов: 6
- Общая выручка: 2155 руб.
- Сумма введённых заказов: 2155 руб.
- Сумма выручек кассиров: 2155 руб.
- Проверка: выручка сходится, все заказы обработаны.

Распределение заказов между кассирами может отличаться при разных запусках программы.
