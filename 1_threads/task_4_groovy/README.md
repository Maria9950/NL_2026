# 1.4. Параллельный анализ массива

**Тема:** Многопоточность  
**Язык:** Groovy  
**Ветка:** `1_task_4_groovy`

## Постановка задачи

Создать четыре потока для независимого анализа одного массива целых чисел.

Потоки подсчитывают количества положительных, отрицательных, чётных и нечётных элементов соответственно.

Главный поток ожидает завершения всех вычислений и выводит результаты.

Ноль считается чётным, но не относится к положительным или отрицательным числам.

**Входные данные:** целые числа, вводимые через пробел.

**Выходные данные:** количество положительных, отрицательных, чётных и нечётных элементов массива, количество нулей и результаты проверки вычислений.

## Запуск программы

Из корневой папки репозитория:

```bash
groovy 1_threads/task_4_groovy/main.groovy
```

## Пример работы

**Входные данные:**

`1 -2 0 3 -5 4`

**Результат:**

- Всего элементов: 6
- Положительных: 3
- Отрицательных: 2
- Чётных: 3
- Нечётных: 3
- Нулей: 1
- Проверка (чётные + нечётные = размер): да
- Проверка (положительные + отрицательные + нули = размер): да
