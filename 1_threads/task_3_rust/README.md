# 1.3. Параллельный поиск самого длинного возрастающего участка

**Тема:** Многопоточность  
**Язык:** Rust  
**Ветка:** `1_task_3_rust`

## Постановка задачи

Дан непустой массив целых чисел. Необходимо найти самый длинный непрерывный участок, в котором каждый следующий элемент строго больше предыдущего.

Разделить массив на блоки и обработать их параллельно. При объединении результатов учитывать возрастающие участки, проходящие через границы блоков.

Вывести длину и границы найденного участка, сравнить результат с последовательным алгоритмом. При равной длине выбирать участок с меньшим начальным индексом.

**Входные данные:** целые числа, вводимые через пробел.

**Выходные данные:** длина найденного участка, начальный и конечный индексы (с нуля), элементы участка и результат сравнения параллельного и последовательного алгоритмов.

## Компиляция и запуск

Из корневой папки репозитория:

```bash
rustc -O 1_threads/task_3_rust/main.rs -o /tmp/nl2026_1_3
/tmp/nl2026_1_3
```

## Пример работы

**Входные данные:**

`2 1 2 3 4 5 6 0`

**Результат:**

- Количество блоков (потоков): 4
- Параллельный результат: длина 6, начало 1, конец 6
- Последовательный результат: длина 6, начало 1, конец 6
- Найденный участок: `[1, 2, 3, 4, 5, 6]`
- Результаты совпадают: да
