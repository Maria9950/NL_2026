# 1.1. Параллельные префиксные суммы

**Тема:** Многопоточность  
**Язык:** Kotlin  
**Ветка:** `1_task_1_kotlin`

## Постановка задачи

Для заданного массива целых чисел параллельно вычислить префиксные суммы: каждый элемент результата равен сумме всех элементов исходного массива от первого до текущего.

Массив разделяется на четыре последовательных блока. Четыре потока независимо вычисляют локальные префиксные суммы, после чего учитываются суммы предшествующих блоков. Результат сравнивается с последовательным вычислением. Для хранения чисел и сумм используется 64-битный тип `Long`.

**Входные данные:** массив целых чисел, вводимых через пробел или запятую.

**Выходные данные:** исходный массив, параллельные и последовательные префиксные суммы, результат их сравнения.

## Запуск программы

Из корневой папки репозитория:

**Компиляция:**

`kotlinc 1_threads/task_1_kotlin/Main.kt -include-runtime -d /tmp/nl2026_1_1.jar`

**Запуск:**

`java -jar /tmp/nl2026_1_1.jar`

## Пример работы

**Входные данные:**

`3 -1 0 5 -2 7 4 -6`

**Результат:**

`[3, 2, 2, 7, 5, 12, 16, 10]`

Параллельные и последовательные результаты совпадают.
