# 2.3. Проверка достижимости в графе

**Тема:** Алгоритмические задачи  
**Язык:** Prolog (SWI-Prolog)  
**Ветка:** `2_task_3_prolog`

## Постановка задачи

Задать ориентированный граф набором фактов о рёбрах. Реализовать рекурсивный предикат, определяющий существование пути между двумя вершинами.

Для предотвращения зацикливания учитывать ранее посещённые вершины.

**Входные данные:** начальная и конечная вершины графа, вводимые через консоль.

**Выходные данные:** сообщение о существовании или отсутствии пути между указанными вершинами.

## Реализация

Граф задан фактами `edge/2`. Для проверки достижимости используется предикат `reachable/2` и рекурсивный обход `walk/3` со списком посещённых вершин.

Программа учитывает направление рёбер, корректно обрабатывает циклы и проверяет существование введённых вершин.

## Запуск программы

Из корневой папки репозитория:

`swipl 2_algorithms/task_3_prolog/main.pl`

## Пример работы

**Входные данные:**

```text
Начальная вершина: a
Конечная вершина: e
```

**Результат:**

```text
Путь из a в e существует.
```

Путь проходит через вершины `a → b → c → e`.
