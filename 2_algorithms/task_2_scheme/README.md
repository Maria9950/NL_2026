# 2.2. Подсчёт элементов вложенного списка

**Тема:** Алгоритмические задачи  
**Язык:** Scheme (GNU Guile)  
**Ветка:** `2_task_2_scheme`

## Постановка задачи

Рекурсивно обойти вложенный список и подсчитать количество всех атомарных элементов. Пустые списки не учитывать.

**Входные данные:** вложенный список в синтаксисе Scheme, вводимый через консоль.

**Выходные данные:** исходный список и количество атомарных элементов.

## Запуск программы

Из корневой папки репозитория:

`guile 2_algorithms/task_2_scheme/main.scm`

## Пример работы

**Входные данные:**

`(a (b c) () (d (e f)))`

**Результат:**

```text
Исходный список: (a (b c) () (d (e f)))
Количество атомарных элементов: 6
```
