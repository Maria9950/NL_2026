# 2.4. Проверка симметрии бинарного дерева

**Тема:** Алгоритмические задачи  
**Язык:** OCaml  
**Ветка:** `2_task_4_ocaml`

## Постановка задачи

Задать бинарное дерево с целочисленными значениями в узлах, используя собственный рекурсивный тип данных.

Реализовать рекурсивную проверку зеркальной симметрии относительно корня. Значения соответствующих узлов должны совпадать, а левое и правое поддеревья — иметь зеркальную структуру.

Продемонстрировать работу на симметричном, несимметричном и пустом деревьях.

**Входные данные:** 12 тестовых бинарных деревьев, заданных в программе.

**Выходные данные:** текстовая схема каждого дерева, результат проверки симметрии и сравнение с ожидаемым ответом.

## Компиляция и запуск

Из корневой папки репозитория:

```bash
ocamlc /tmp/nl_2_4_ocaml/main.ml -o /tmp/nl_2_4_ocaml/main
/tmp/nl_2_4_ocaml/main
```

## Пример работы

Для дерева с корнем `1` и двумя одинаковыми листьями `2`:

```text
Ожидается: симметрично; получено: симметрично; OK
```

Для дерева с корнем `1` и листьями `2` и `3`:

```text
Ожидается: несимметрично; получено: несимметрично; OK
```

Итог проверки:

```text
Все тесты пройдены: да
```
